# Analysis and Resizing of the Concorde Rolls-Royce/Snecma Olympus 593MK610

This repository contains the MATLAB and Python codes developed for the university project *Analysis and Resizing of the Concorde Rolls-Royce/Snecma Olympus 593MK610*, carried out as part of the final coursework requirements for the Bachelor's Degree in Aerospace Engineering at Politecnico di Milano.

The project focuses on the analysis and preliminary resizing of the Rolls-Royce/Snecma Olympus 593MK610 turbojet engine, mounted on the Concorde supersonic transport aircraft. The numerical codes were used to support the study of different engine operating conditions, including take-off, noise abatement climb, maximum climb, and supersonic cruise.

The computational work includes the analysis of the engine thermodynamic cycle, intake shock-wave system, compressor parameters, velocity triangles, nozzle behavior, and performance-related quantities. Part of the project also investigates a possible engine redesign aimed at improving efficiency and reducing jet noise, considering an associated-flow turbofan configuration, bypass ratio effects, and preliminary noise-reduction concepts such as chevrons.

The scripts are intended to reproduce and support the calculations presented in the project report, where MATLAB and Python were used as computational environments alongside GasTurb13, SolidWorks, and ANSYS for engine simulation, design, and fluid-dynamic analysis.

## Project context

This repository is associated with an academic aerospace engineering project and is not an official publication of Politecnico di Milano. The codes are shared for documentation, reproducibility, and portfolio purposes.
